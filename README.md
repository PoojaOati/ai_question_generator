# AI Quiz Generator 🧠

This AI agent allows users to upload a PDF or input text and automatically generates quiz-style questions from the content using NLP models.

## Features

- Upload PDFs or enter paragraphs
- Automatically generate questions
- Choose output language
- User-friendly Streamlit interface

## Usage

1. Click "Open in Spaces"
2. Upload a PDF or input your content
3. Click "Generate Questions"
4. Copy or download the generated quiz

## Tech Stack

- 🤗 Transformers
- PyTorch
- Streamlit
- pdfplumber
